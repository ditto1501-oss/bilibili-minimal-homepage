# Bilibili 极简首页

一个用于 Bilibili 的用户脚本：打开 `https://www.bilibili.com/` 首页时，隐藏原有首页内容，只显示一个居中的搜索框。

## 功能

- 简化 Bilibili 首页，减少首页内容干扰
- 保留搜索入口
- 脚本只针对 `www.bilibili.com/` 首页

## 安装

1. 安装支持用户脚本的浏览器扩展。
2. 打开本仓库中的 `bilibili-minimal-homepage.user.js`。
3. 复制文件内容，在用户脚本扩展中新建脚本并粘贴保存。
4. 打开或刷新 `https://www.bilibili.com/` 查看效果。

## 说明

这是个人制作的简单脚本。如果 Bilibili 更新页面结构，脚本可能需要调整。
